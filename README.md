# Trading

## neuro-stimulus-map

[`neuro-stimulus-map/`](neuro-stimulus-map/README.md) contains **Brain Heat Map**, a web app that plays a video, song or podcast alongside an estimated brain heat map: which brain areas curated, cited research links to the kinds of input playing at each moment. It is an estimate, not a brain recording or scan, and an Evidence view shows every link behind it.
