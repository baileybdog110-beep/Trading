PropPath

Connect Tradovate

Use the Tradovate login that holds your Apex accounts. This is read-only: PropPath never places or changes orders. Your password and token stay in memory and are never saved.

API keys come from Tradovate → Application Settings → API Access. They need Tradovate's API add-on. No API access? Use Import CSV. It works for every account.

Choose accounts

Check the phase and size. PropPath guesses them from the account name and balance.

Import trades

  1. In Tradovate, open Account Reports and pick the account.
  2. Choose the Performance tab, set the date range to cover the whole account and click Download.
  3. Drop the CSV here. NinjaTrader trade exports and most trade-journal CSVs work too.

Tradovate's Performance P&L doesn't include commissions. Add yours (often $3–4 per contract round-turn on Apex) or enter your current balance so every number matches.
